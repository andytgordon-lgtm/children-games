# Sound World

**Sound World** is a UK phonics and counting web app for young children and parents. Families play in themed worlds (trains, planes, dinosaurs, farm animals), guided by Mum, Dad, Brother, Sister, and pets — optionally using family photos in themed frames and later cartoon caricatures. A gated Parent Coach gives parents tips and practice ideas; kids never get freeform AI chat.

This repository is the home of Sound World. App scaffolding has not started yet — docs only for now.
